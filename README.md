# E-Commerce-Churn-Analysis-MYSQL
Analyzed an e-commerce customer dataset using MySQL to identify churn patterns, customer behavior, and key factors influencing retention. Performed data cleaning, aggregation, and KPI analysis to generate actionable business insights.

📌 Project Overview
This project focuses on analyzing customer churn behavior in an e-commerce business using MySQL. The objective is to identify patterns in customer retention, understand key churn drivers, and generate actionable business insights.
The analysis includes customer demographics, purchase behavior, satisfaction scores, and churn trends.

🎯 Objectives
- Calculate overall churn rate
- Identify churn distribution by gender and demographics
- Analyze relationship between order frequency and churn
- Evaluate customer satisfaction impact on churn
- Detect duplicate records and ensure data integrity
- Create churn labels for better interpretability

🛠️ Tools & Technologies
MySQL – Data querying and analysis

SQL Concepts Used:
- Aggregations (COUNT, SUM, AVG)
- CASE WHEN statements
- GROUP BY, HAVING
- Data cleaning queries
- Derived columns

📊 Key Insights
- Identified churn rate using aggregated churn column
- Observed trends between low order count and higher churn probability
- Compared satisfaction scores between churned and retained customers
- Generated structured dataset for further visualization and modeling

- 📊 Build an interactive Tableau dashboard to visualize churn KPIs and customer behavior.
- 🤖 Develop a machine learning model to predict customer churn and evaluate performance using standard metrics.
